### Chapter Goal
এই চ্যাপ্টারের মূল লক্ষ্য হলো আর্টিফিশিয়াল ইন্টেলিজেন্সের তিনটি প্রধান স্তম্ভ—মেশিন লার্নিং (Machine Learning), ডিপ লার্নিং (Deep Learning) এবং কৃত্রিম নিউরাল নেটওয়ার্ক (Artificial Neural Networks) এর মধ্যকার পারস্পরিক সম্পর্ক এবং তাদের ভেতরের মেকানিক্স বোঝা। এছাড়াও আমরা শিখবো সুপারভাইজড, আনসুপারভাইজড এবং রিইনফোর্সমেন্ট লার্নিংয়ের প্র্যাক্টিক্যাল পার্থক্য ও তাদের বাস্তব প্রয়োগ।

### Why Should I Care?
সব এআই প্রজেক্ট একভাবে হ্যান্ডেল করা যায় না। কাস্টমার চিলড্রেন সেগমেন্টেশন, ক্রেডিট কার্ড ফ্রড ডিটেকশন আর সেলফ-ড্রাইভিং কার—তিনটির আর্কিটেকচার সম্পূর্ণ ভিন্ন। কোনটি মেশিন লার্নিং দিয়ে সলভ করবে আর কোনটির জন্য কোটি টাকার ডিপ লার্নিং মডেল বানাবেন, এই সিদ্ধান্ত নিতে না পারলে এআই ইঞ্জিনিয়ার হিসেবে তোমার প্রোজেক্ট কস্ট ও রিসোর্স ম্যানেজমেন্ট ট্র্যাশে চলে যাবে।

### Big Picture
আগের চ্যাপ্টারে আমরা ক্লাসিক্যাল কোডিং ও এআই এর মধ্যকার গ্যাপ বা Software 2.0 প্যারাডাইম শিফট দেখেছি। এই চ্যাপ্টারে আমরা দেখবো কীভাবে এই সফটওয়্যার ২.০ ইকোসিস্টেম বিভিন্ন সাব-ক্যাটাগরিতে বিভক্ত এবং কীভাবে তারা মানুষের ব্রেইনের অনুকরণে কাজ করে।

### ২. Core Concepts: লার্নিং টাইপস ও এনাটমি

#### ক. Supervised vs. Unsupervised vs. Reinforcement Learning

এআই ট্রেইনিংয়ের মূলত তিনটি পথ রয়েছে:

##### ১. Supervised Learning (তত্ত্বাবধায়ক শিক্ষণ)
* **কনসেপ্ট:** এখানে প্রতিটি ইনপুটের সাথে তার সঠিক লেবেল বা উত্তর জুড়ে দেওয়া থাকে (Labeled Data)।
* **ফর্মুলা:** $Y = f(X)$ যেখানে $X$ হলো ইনপুট ফিচার এবং $Y$ হলো লেবেল।
* **রিয়েল লাইফ অ্যানালজি:** শিক্ষক ক্লাসে প্রশ্নের সাথে উত্তর বুঝিয়ে দিচ্ছেন, আর ছাত্র তা মুখস্থ/শিখে পরীক্ষা দিচ্ছে।
* **ইউজ কেস:** স্প্যাম ফিল্টারিং, ইমেজ ক্লাসিফিকেশন।

##### ২. Unsupervised Learning (স্বয়ংক্রিয় শিক্ষণ)
* **কনসেপ্ট:** এখানে কোনো সঠিক লেবেল বা উত্তর দেওয়া থাকে না (Unlabeled Data)। মডেলকে নিজে নিজেই ডেটার প্যাটার্ন ও ক্লাস্টার খুঁজে বের করতে হয়।
* **রিয়েল লাইফ অ্যানালজি:** কোনো ট্রেইনার ছাড়া কাস্টমারের কেনাকাটার অভ্যাস দেখে তাদেরকে বিভিন্ন ক্যাটাগরিতে ভাগ করা।
* **ইউজ কেস:** কাস্টমার সেগমেন্টেশন, অ্যানোমালি ডিটেকশন।

##### ৩. Reinforcement Learning (পুরস্কার-শাস্তি ভিত্তিক শিক্ষণ)
* **কনসেপ্ট:** কোনো পূর্ববর্তী ডেটা থাকে না। একটি এজেন্ট কোনো এনভায়রনমেন্টে অ্যাকশন নেয় এবং তার আউটপুট অনুযায়ী রিওয়ার্ড (Reward) অথবা পেনাল্টি (Penalty) পায়।
* **রিয়েল লাইফ অ্যানালজি:** একটি বাচ্চাকে সাইকেল চালানো শেখানো—পড়ে গেলে ব্যথা পাবে (Penalty), ব্যালেন্স রাখলে এগিয়ে যাবে (Reward)।
* **ইউজ কেস:** দাবা খেলা (AlphaGo), রোবোটিক্স, রিজনিং মডেল (DeepSeek R1)।

#### খ. Machine Learning বনাম Deep Learning এর আসল পার্থক্য

এদের মধ্যে মৌলিক পার্থক্য হলো **ফিচার ইঞ্জিনিয়ারিং (Feature Engineering)**।

* **Machine Learning:** তোমাকে ম্যানুয়ালি ফিচার এক্সট্রাক্ট করে দিতে হয়। যেমন: বাড়ি বিক্রির প্রেডিকশন মডেলে তোমাকে আলাদা করে রুমের সংখ্যা, লোকেশনের রেটিং ইনপুট ফিচার হিসেবে গুছিয়ে দিতে হবে।
* **Deep Learning:** মডেল ইমেজ বা র টেক্সটের পিক্সেল লেভেল থেকে নিজেই অবজেক্টের কনট্যুর, এজ, চোখ, নাক ইত্যাদি অটোমেটিক্যালি এক্সট্রাক্ট বা লার্ন করে। মানুষের হস্তক্ষেপের প্রয়োজন হয় না।

### ৫. Developer Perspective: ক্লাসিক্যাল এমএল (Scikit-Learn) বনাম ডিপ লার্নিং (Keras/PyTorch)

💻 Developer View

চলো পাইথনে Scikit-Learn (ML) এবং Keras (DL) দিয়ে একই প্রবলেম সলভ করার কোডিং প্যাটার্ন দেখে নিই।

```python
# --- ১. MACHINE LEARNING (Tabular classification using Decision Trees) ---
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier
from sklearn.metrics import accuracy_score

# Iris dataset loaded (তাবুলার ডেটা)
data = load_iris()
X_train, X_test, y_train, y_test = train_test_split(data.data, data.target, test_size=0.2)

# Simple ML Classifier
ml_model = DecisionTreeClassifier()
ml_model.fit(X_train, y_train)

y_pred = ml_model.predict(X_test)
print(f"ML Decision Tree Accuracy: {accuracy_score(y_test, y_pred) * 100:.2f}%")
```

এখন দেখা যাক কীভাবে আমরা ডিপ লার্নিং (Keras) ব্যবহার করে নিউরাল নেটওয়ার্ক দাঁড় করাবো:

```python
# --- ২. DEEP LEARNING (Multi-layer Perceptron using Keras) ---
import tensorflow as tf
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Dense

# Deep Neural Network Architecture
dl_model = Sequential([
    Dense(16, activation='relu', input_shape=(4,)), # Input Layer + Hidden Layer 1
    Dense(8, activation='relu'),                   # Hidden Layer 2
    Dense(3, activation='softmax')                 # Output Layer (3 Classes)
])

# Compile Model
dl_model.compile(optimizer='adam',
                 loss='sparse_categorical_crossentropy',
                 metrics=['accuracy'])

# Train Model
dl_model.fit(X_train, y_train, epochs=20, batch_size=4, verbose=0)

loss, accuracy = dl_model.evaluate(X_test, y_test, verbose=0)
print(f"Deep Learning Neural Network Accuracy: {accuracy * 100:.2f}%")
```

* **সার্ভিং কস্ট:** সাধারণ এমএল মডেল সিপইউতেই (CPU) মাইক্রো-সেকেন্ডে রান করে। আর ডিপ লার্নিং বা ট্রান্সফর্মার মডেলের জন্য জিপিইউ (GPU) ও মেমোরি কস্ট প্রতি মাসে হাজার ডলার ছাড়িয়ে যেতে পারে।

### ৭. Common Mistakes

🔴 Common Mistake

**ভুল ধারণা:** ডিপ লার্নিং সব সময় মেশিন লার্নিং অ্যালগরিদমের চেয়ে বেশি নিখুঁত বা এক্যুরেট হবে।

**বাস্তবতা:** ট্যাবুলার বা এক্সেল শিট ডেটার ক্ষেত্রে ডিপ লার্নিং অনেক সময় বুস্টেড ট্রিস (যেমন XGBoost বা LightGBM) এর চেয়ে খারাপ পারফর্ম করে। নিউরাল নেটওয়ার্ক তৈরিই হয়েছে ইমেজ, টেক্সট এবং অডিওর মতো চরম নন-লিনিয়ার আনস্ট্রাকচারড ডেটার ভেতরের হিডেন রিলেশনশিপ বোঝার জন্য।

### ৯. Mini Project: কাস্টমার রিটেনশন ক্লাসিফায়ার

চলো NumPy ব্যবহার করে একটি অত্যন্ত সহজ লিনিয়ার ক্লাসিফায়ার বানাই যা ইউজারের লগইন ফ্রিকোয়েন্সি ও সাবস্ক্রিপশন ফি দেখে সে লিভ (Churn) করবে কি না তা প্রেডিক্ট করবে।

```python
import numpy as np

# ১. ফিচার: [লগইন দিন/সপ্তাহে, সাবস্ক্রিপশন প্রাইস ($)]
X = np.array([
    [7, 10],   # ইউজার ১: অ্যাক্টিভ
    [6, 15],   # ইউজার ২: অ্যাক্টিভ
    [1, 9],    # ইউজার ৩: ইন-অ্যাক্টিভ (Churn)
    [2, 30]    # ইউজার ৪: ইন-অ্যাক্টিভ (Churn)
])
Y = np.array([1, 1, 0, 0]) # ১ = রিটেইনড, ০ = চার্নড

# ২. র্যান্ডম প্যারামিটার
W = np.array([0.1, -0.2])
B = 0.0

# ৩. অ্যাক্টিভেশন ফাংশন (হাইভিসাইড স্টেপ ফাংশন)
def predict(features):
    score = np.dot(features, W) + B
    return 1 if score >= 0 else 0

# ৪. র্যান্ডম প্রেডিকশন চেক
test_user = np.array([7, 12])
print(f"Prediction for active user (7 logins, $12): {'Retained' if predict(test_user) == 1 else 'Churned'}")
```

### ১০. Interview Questions

#### Beginner
1. **প্রশ্ন:** মেশিন লার্নিং এবং ডিপ লার্নিংয়ের মধ্যে প্রধান পার্থক্য কী?
   * **উত্তর:** মেশিন লার্নিং অ্যালগরিদমে ডেটার ফিচারগুলো মানুষের ম্যানুয়ালি এক্সট্রাক্ট করে দিতে হয় (Feature Engineering)। আর ডিপ লার্নিংয়ে নিউরাল নেটওয়ার্ক নিজে নিজেই ডেটার পিক্সেল বা র ফাইল থেকে হিডেন ফিচার শিখে নেয়।

#### Intermediate
2. **প্রশ্ন:** রিইনফোর্সমেন্ট লার্নিং এবং সুপারভাইজড লার্নিংয়ের পার্থক্য প্র্যাক্টিক্যাল এক্সাম্পল দিয়ে ব্যাখ্যা করো।
   * **উত্তর:** সুপারভাইজড লার্নিং চলে লেবেলড ডেটার উপর—যেমন ছবি এবং ছবির নাম (বিড়াল/কুকুর)। কিন্তু রিইনফোর্সমেন্ট লার্নিং কোনো ডেটা ছাড়াই শুরু হয়। একটি এআই এজেন্ট এনভায়রনমেন্টে অ্যাকশন নিয়ে নিজের ভুলের জন্য পেনাল্টি আর সঠিক চালের জন্য রিওয়ার্ড পেয়ে ধীরে ধীরে বেস্ট পাথ শেখে (যেমন রোবট হাঁটা শেখা)।

#### Advanced
3. **প্রশ্ন:** ট্যাবুলার ডেটাবেস অ্যানালাইসিস করতে তুমি XGBoost নাকি কাস্টম Multi-Layer Perceptron (Neural Network) সিলেক্ট করবে? কেন?
   * **উত্তর:** ট্যাবুলার ডেটার জন্য XGBoost বা LightGBM সিলেকশনই প্রোডাকশন-গ্রেড সিদ্ধান্ত। কারণ ট্যাবুলার ডেটাতে ফিচারগুলো অলরেডি স্ট্রাকচারড থাকে, যার জন্য বুস্টেড ট্রিস অনেক দ্রুত কনভার্জ করে এবং কম্পিউটেশনাল খরচ ও ওভারফিটিং রিস্ক অনেক কম হয়। নিউরাল নেটওয়ার্ক সাধারণত ইমেজ বা আনস্ট্রাকচারড সিকোয়েনশিয়াল ডেটার জন্য বেশি উপযোগী।
